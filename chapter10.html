Chapter 10: Floating and Positioning

Positioning

Define where element boxes will appear relative to their default position

Types of Positioning

  • Static: Default positioning, elements flow in the normal document flow.
  • Relative: Positioned relative to its normal position.
  • Absolute: Positioned relative to the nearest positioned ancestor.
  • Fixed: Positioned relative to the viewport, stays in place during scrolling.
  • Sticky: Switches between relative and fixed, depending on scroll position.

The Containing Block

The ancestor element that determines the positioning context for an element. For relative or static positioned elements, it is formed by the content edge of nearest block-level, table-cell, or inline-block ancestor. For absolutely positioned elements, it is the nearest ancestor with a position other than static.

Offset Properties

The properties used to describe the offset of a positioned element relative to it's containing block.

Positive values cause inward movement, while negative values cause outward movement.

Example 1: Horizontal Offset (left)

A moves right with a positive value, B moves left with a negative value.

A
B
.box-a { left: 6px; }   /* positive: right */
.box-b { left: -6px; }  /* negative: left */

Example 2: Vertical Offset (top)

C moves down with a positive value, D moves up with a negative value.

C
D
.box-c { top: 4px; } /* positive: down */
.box-d { top: -4px; } /* negative: up */

Absolute Positioning

Absolute positioning removes an element from normal flow and places it relative to the nearest positioned ancestor. If no ancestor is positioned, it is placed relative to the initial containing block.

Absolute

.container {
  position: relative;
}

.absolute-box {
  position: absolute;
  top: 0.5rem;
  right: 0.5rem;
}

Sticky Positioning

Sticky positioning is a hybrid of relative and fixed positioning. The element is treated as relative until it crosses a specified threshold, at which point it becomes fixed.

Sticky

  top: 0;
}
