# CSS The Definitive Guide - Book Studies

This repository contains study notes and live HTML examples based on concepts from CSS: The Definitive Guide.

## Purpose

- Practice core CSS layout and positioning concepts.
- Keep examples small, visual, and easy to inspect.
- Build chapter-focused reference pages for quick review.

## Project Structure

- index.html: Landing page for navigating chapter study files.
- chapter10.html: Notes and live demos for floating and positioning, including relative, absolute, and fixed positioning examples.

## How To View

1. Open the repository folder in VS Code.
2. Open index.html or chapter10.html in your browser.
3. Refresh the page after making edits.

## Current Focus

- Chapter 10: Floating and Positioning
- Offset behavior with positive and negative values
- Containing blocks and corner placement examples

## Notes

This is a lightweight static HTML study project. No build tools, dependencies, or framework setup are required.
