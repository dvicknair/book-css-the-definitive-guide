Chapter 11: Flexbox Layout

Flexbox Containers

Flexbox is a layout model built for distributing space among items in one dimension. The parent element becomes a flex container.

display: flex

The most common flex container makes a block-level flex container.

1
2
3
.container {
  display: flex;
}

display: inline-flex

An inline flex container behaves like an inline element while still creating a flex layout.

A B C 
.inline-container {
  display: inline-flex;
}

Gap

Gap adds spacing between flex items without requiring margins. This works for both row and column gaps.

Summary

Flexbox gives you control over how items flow in one dimension. Use display: flex or display: inline-flex to create containers, choose a main axis with flex-direction, allow wrapping with flex-wrap, and align items with justify-content, align-items, align-self, and place-content. The gap property adds clean spacing without extra markup.
